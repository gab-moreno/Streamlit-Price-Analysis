The Tool

App Highlights

📄

PDF → Data Automatically

Upload supplier quote PDFs. Power Automate extracts all line items and loads them into a review table — no re-typing.

✏️

Live Editable Table

Review, add, or remove rows directly in the app. Adjust quantities, descriptions, or supplier entries on the fly.

💲

Configurable Tax

Set the tax percentage once (default 12%). All totals — including the final Excel — update instantly.

👀

HTML Preview

See the full price comparison table — organized by product code and supplier — before generating the file.

🏆

Auto Winner Detection

The lowest-priced supplier per item is automatically highlighted in green in the final Excel. No manual comparison needed.

📥

Professional Excel Output

Generates a formatted, formula-driven Excel with merged cells, color-coded headers, and dynamic price calculations.
